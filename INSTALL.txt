StudyFlow 1.0.0 — практичне заняття 17
Виконав: Трасковський Богдан.

Вимоги: Windows 10/11 x64. Для готових EXE окрема інсталяція Python не потрібна.

1. Розпакуйте StudyFlow-Windows-x64.zip у будь-яку папку.
2. Запустіть StudyFlow.exe (графічний інтерфейс) або StudyFlow-CLI.exe (консоль).
3. Дані зберігаються автоматично у %LOCALAPPDATA%/StudyFlow/studyflow.db.
   Якщо в робочій папці вже є studyflow.db, буде використано її.
4. Резервні копії JSON створюються через графічне меню або команду save.
5. Для видалення програми достатньо видалити розпаковані файли.
   Базу даних видаляйте тільки після створення копії, якщо вона більше не потрібна.

Виконувані файли не мають цифрового підпису. Windows може показати попередження.
Вихідний код: https://github.com/xyedress/121212

# StudyFlow — фінальна перевірка (практичне заняття № 18)

**Виконав: Трасковський Богдан.**  
Версія: 1.0.1. Власна тема: планувальник навчальних завдань.

## Матриця вимог

| Компонент | Вимога для обраної теми | Реалізація | Перевірка |
|---|---|---|---|
| CLI | Створення через діалог або аргументи, перегляд, зміна, завершення, видалення | studyflow/cli.py | tests/test_studyflow.py |
| CORE | Валідація, терміновість, сортування, прогрес, періоди | studyflow/core.py | tests/test_business_logic.py, tests/test_finalization.py |
| DATA | Постійне збереження, резервний знімок, відновлення | studyflow/data.py, studyflow/persistence.py | tests/test_persistence.py |
| GUI | Таблиця, пошук, фільтри, CRUD, прогрес, JSON | studyflow/gui.py, studyflow/gui_controller.py | tests/test_gui_controller.py, tests/gui_acceptance.py |
| Розгортання | Готовий переносний Windows-пакет, інструкція, контрольна сума | build.ps1, requirements-build.txt, .github/workflows/release.yml | Windows Release, CRC, MZ |
| Документація | Архітектура, UML, формули, схема даних, інтерфейси, інструкції | DESIGN.md, README.md, INSTALL.txt | Перегляд документації |

Тема 3 була запропонована в практичній № 13. Застосунок не є каталогом персонажів або текстовою грою; фінальна матриця адаптує загальні вимоги до власної теми.

## Автоматизовані перевірки

- 52 модульні тести: python -m unittest discover -s tests -v
- 2 інтеграційні тести Tk: python -m unittest discover -s tests -p gui_acceptance.py -v
- Запуск готових GUI/CLI EXE, запис у SQLite, перевірка ZIP та контрольної суми.
- Результати конкретної збірки: [Actions](https://github.com/xyedress/121212/actions). Публікація релізу відбувається лише після успішних перевірок.

## Сценарій ручної приймальної перевірки

| Крок | Очікуваний результат |
|---|---|
| Розпакувати ZIP, запустити StudyFlow.exe | Відкривається головне вікно |
| Додати завдання з коректним дедлайном | Рядок з'являється в таблиці |
| Ввести некоректний дедлайн | Повідомлення про помилку, запис не додається |
| Знайти завдання за назвою, застосувати фільтр | Таблиця показує відповідні записи |
| Змінити дедлайн та позначити виконання | Статус і прогрес оновлюються |
| Зберегти JSON; видалити запис; відновити копію | Повертається збережений запис |
| Закрити програму, запустити повторно | Завдання збережено |
| Запустити StudyFlow-CLI.exe, виконати help і list | Команди працюють, відображаються спільні дані |
| Перевірити SHA-256 архіву | Збігається з SHA256SUMS.txt |

Ручні сценарії — інструкція для перевіряльника, а не звіт про вже виконані вручну дії.

## Межі та залежності

Windows 10/11 x64; готові EXE не потребують окремого Python. Для розробки потрібен Python 3.10+ із Tkinter; для збірки — Python 3.11 x64, pip, PyInstaller із requirements-build.txt. Програма працює локально, без вебсервера. Дані користувача не включені у ZIP. Заміна даних із JSON потребує підтвердження; EXE не мають цифрового підпису.
